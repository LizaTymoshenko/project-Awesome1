# Персональний помічник

Консольний бот: книга контактів і нотатки. Дані зберігаються на диску, тож бота можна перезапускати без втрати даних. Структура модулів і потік даних описані в [ARCHITECTURE.md](./ARCHITECTURE.md).

## Встановлення і запуск

Потрібні Python 3.12+ і `uv`. З кореня репозиторію:

```bash
uv sync
uv run python src/main.py
```

Тести: `uv run pytest`. Лінтер: `uv run ruff check .`.

## Приклад сеансу

Після запуску помічника введіть:

```text
add Olena 0501234567
search Olena
add-note Підготувати звіт до п’ятниці
notes
add-tag 1 робота
search-tag робота
exit
```

`1` — ID першої нотатки в порожній книзі. Якщо у вашої нотатки інший ID, підставте його зі списку `notes`. Після наступного запуску контакт і нотатка залишаться доступними.

## Структура

`src/main.py` запускає помічника. Моделі контактів і нотаток лежать у `src/address_book/` і `src/notebook/`, обробники й реєстр команд — у `src/handlers/` і `src/registry/`. За консоль відповідає `src/console/`, за збереження — `src/storage/`. Допоміжні функції лежать у `src/helpers/`, тести — у `tests/`.

## Команди

`help` показує всі команди. `Tab` доповнює назви, стрілки ↑ і ↓ перегортають історію поточного сеансу, а під рядком вводу видно формат команди. Якщо в назві є помилка, бот підказує схожу команду, коли знаходить збіг.

### Контакти

| Команда | Що робить |
|---------|-----------|
| `add [імʼя] [телефон]` | створює контакт або додає телефон |
| `change [імʼя] [старий] [новий]` | змінює телефон |
| `remove-phone [імʼя] [телефон]` | видаляє вказаний телефон контакту |
| `phone [імʼя]` | показує телефони контакту |
| `delete [імʼя]` | видаляє контакт |
| `all` | показує всі контакти таблицею |
| `search [запит]` | шукає контакти за імʼям, телефоном або email |
| `add-address [імʼя] [адреса]` | додає адресу |
| `add-email [імʼя] [email]` | додає email (формат перевіряється) |
| `edit [імʼя] [name\|address\|email\|birthday] [значення]` | змінює поле контакту |
| `add-birthday [імʼя] DD.MM.YYYY` | додає день народження |
| `show-birthday [імʼя]` | показує день народження |
| `birthdays [N]` | показує дні народження на найближчі N днів (типово 7) |

### Нотатки

| Команда | Що робить |
|---------|-----------|
| `add-note [текст]` | створює нотатку |
| `notes` | показує всі нотатки таблицею |
| `search-note [текст]` | шукає нотатки за текстом |
| `edit-note [id] [новий текст]` | змінює текст нотатки |
| `delete-note [id]` | видаляє нотатку |
| `add-tag [id] [тег1] [тег2] ...` | додає один або кілька тегів |
| `remove-tag [id] [тег]` | видаляє тег із нотатки |
| `search-tag [тег]` | шукає нотатки за тегом |
| `sort-notes` | групує нотатки за тегами й сортує групи |

`hello` — привітання. `exit` або `close` — вихід зі збереженням.

## Як додати команду

Додайте обробник у `src/handlers/` і зареєструйте його в `init_registry()` у `src/registry/commands.py`. Формат і опис із реєстру автоматично зʼявляться в `help` і підказках.

## Дані

Контакти й нотатки зберігаються через `pickle` у `~/.personal_assistant/assistant.pkl` під час виходу.
